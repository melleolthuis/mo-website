# Kleine website met 3 pagina's

Bestanden toegevoegd:

- `index.html` — Homepagina
- `about.html` — Over mij
- `request.html` — Klussen aanvragen (formulier, client-side bevestiging)
- `styles.css` — Basisstyling

Open `index.html` in je browser om de site lokaal te bekijken. Als je wilt dat het formulier echte e-mails verstuurt, kan ik een eenvoudige backend of een formulierdienst integreren.
